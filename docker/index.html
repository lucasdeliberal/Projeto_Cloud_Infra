☁️ Projeto Cloud Infra AWS

Projeto prático de Infraestrutura Cloud, Kubernetes e SRE, desenvolvido com foco em ambiente realista de produção, cobrindo provisionamento, CI/CD, observabilidade, alertas e SLOs.

Este projeto foi criado como portfólio técnico, refletindo cenários reais enfrentados por times de Infra, Cloud, DevOps e SRE.

🎯 Objetivo do Projeto

Projetar, implementar, operar e documentar uma infraestrutura Kubernetes funcional na AWS, utilizando componentes open-source e soluções custo-efetivas.

  • Kubernetes (k3s) em ambiente cloud
  • Exposição segura de aplicações (Ingress + TLS)
  • DNS e HTTPS com certificados válidos
  • CI/CD com GitHub Actions
  • Observabilidade completa (métricas, dashboards e alertas)

🧱 Arquitetura Geral

☁️ Cloud & Infra

  • Cloud Provider: AWS
  • Região: sa-east-1 (São Paulo)
  • Recursos Utilizados: EC2, Route53
  • Sistema Operacional: Ubuntu Server
  • Rede: VPC e subnets AWS
  • IP Público: Elastic IP
  • Domínio: lucasdeliberal.com.br

🐳 Aplicação

  • Tipo: Site estático (portfolio técnico)
  • Servidor Web: NGINX
  • Containerização: Docker
  • Registry: GitHub Container Registry (GHCR)
  • Imagem: ghcr.io/lucasdeliberal/portfolio-site:latest

A aplicação é propositalmente simples. O foco do projeto está 100% na infraestrutura.

🌐 Exposição da Aplicação

  • Service (ClusterIP): Comunicação interna entre Pods
  • Ingress (NGINX): Roteamento HTTP/HTTPS e terminação TLS
  • DNS + Elastic IP (AWS): Domínios apontando para Elastic IP

🔐 HTTPS & Certificados

  • Ferramenta: cert-manager

Certificados TLS emitidos automaticamente e renovados sem intervenção manual.

🔁 CI/CD — GitHub Actions

  • Push para a branch main
  • Build da imagem Docker
  • Push para o GitHub Container Registry
  • Deploy automático no cluster Kubernetes

🔐 Segurança e Autenticação

  • ServiceAccount dedicada no cluster
  • RBAC com permissões mínimas
  • Kubeconfig exclusivo para CI
  • Secrets armazenados no GitHub

👤 Sobre mim

Analista de Infraestrutura e Cloud, com atuação em cenários híbridos (on-premises e AWS), envolvendo servidores Linux e Windows, redes, segurança e automação. No dia a dia, trabalho com troubleshooting de ambientes críticos, sustentação de serviços essenciais e implementação de soluções focadas em alta disponibilidade, segurança e escalabilidade.

Este projeto foi desenvolvido como uma forma prática de consolidar e demonstrar conhecimentos em Kubernetes, CI/CD, observabilidade e práticas de SRE, aplicados em um ambiente que simula cenários reais de produção, desde a infraestrutura até a operação contínua.

O objetivo não é apenas apresentar ferramentas, mas evidenciar processo, tomada de decisão técnica, pensamento operacional e maturidade profissional, alinhados às demandas reais de times de Infra, Cloud, DevOps e SRE.
